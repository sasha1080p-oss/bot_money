# «Деньги» — подушка безопасности и хотелки (Telegram Mini App)

Принцип «плати сначала себе»: с каждого поступления процент автоматически
уходит в две копилки — подушку безопасности и фонд хотелок. Всё управление
в Mini App внутри Telegram; бот только открывает приложение.

## Что внутри

```
cushion_bot.py      бот + веб-сервер + API (один процесс)
webapp/index.html   Mini App
requirements.txt
Procfile
```

В приложении три вкладки:
- **🔒 Подушка** — прогресс текущего этапа, список этапов и их изменение, снятие на форс-мажор с причиной, правило неприкосновенности;
- **🎯 Хотелки** — очередь целей: добавить, изменить, удалить, купить текущую;
- **🕘 История** — все поступления и снятия.

Внизу на любой вкладке — проценты (подушка, хотелки, неожиданные деньги), месячные расходы и валюта.

## Деплой на Railway

1. Запушь эту папку в репозиторий `bot_money`, Railway подхватит его сам.
2. **Settings → Networking → Generate Domain** — получишь адрес вида `https://bot-money-production.up.railway.app`.
3. **Volume**: добавь Volume к сервису с mount path `/data`.
4. **Variables**:
   - `BOT_TOKEN` — токен от BotFather;
   - `DB_PATH` — `/data/cushion.db`.
   `WEBAPP_URL` задавать не нужно: адрес берётся из домена Railway. Задай вручную, только если используешь свой домен.
5. После деплоя напиши боту `/start`. Слева от поля ввода появится кнопка «Деньги».

Без Volume база будет обнуляться при каждом редеплое.

## Локальный запуск

Mini App открывается только по https, поэтому локально нужен туннель
(например `ngrok http 8080`):

```
pip install -r requirements.txt
export BOT_TOKEN=токен
export WEBAPP_URL=https://адрес-из-ngrok
python cushion_bot.py
```

## Безопасность

Каждый запрос к API подписан Telegram (`initData`), сервер проверяет подпись
токеном бота. Каждый пользователь видит только свои данные.
