# Бот «подушка безопасности» (pay yourself first)

Логика бота — не отслеживать мелкие траты, а автоматически откладывать
процент с каждого поступления денег в две копилки: подушку безопасности
и фонд хотелок. Управление — через кнопки под сообщениями, набирать
текстовые команды не нужно (кроме ввода чисел и названий, когда бот сам
об этом просит).

## Запуск

```
pip install -r cushion_requirements.txt
export BOT_TOKEN=токен_от_BotFather
python cushion_bot.py
```

Напиши боту `/start` — дальше всё через кнопки.

## Как это устроено

С каждого поступления:
- 🔒 % в подушку безопасности (по умолчанию 20%, не трогать)
- 🎯 % в фонд хотелок (по умолчанию 10%, можно тратить без вины)
- 💳 остальное — обычная жизнь

Подушка проходит через этапы (по умолчанию 100 000 → 500 000 → 1 000 000,
плюс финальный этап «6 месяцев расходов», если задать месячные расходы в
настройках). Хотелки — это очередь: копится только на первую цель, после
покупки — переход к следующей.

## Кнопки главного меню

- **💰 Доход** — записать поступление (бот сам спросит сумму и обычный ли это доход или неожиданный)
- **📊 Статус** — текущий прогресс подушки и активной хотелки, с картинкой
- **🎯 Хотелки** — очередь целей: добавить, купить текущую, пропустить текущую
- **🔓 Снять деньги** — снять из подушки на форс-мажор (с проверкой остатка)
- **📜 Правило** — когда подушку можно трогать
- **⚙️ Настройки** — проценты (подушка / хотелки / бонус), месячные расходы, суммы этапов подушки, валюта

Валюта по умолчанию AMD, меняется в настройках на любую (например $, €, ֏).
